## 30 秒查看结果

在预注册的 **60 个 DeepSWE / CCBench 真实工程任务**上，采用同模型、同预算、官方验证器进行跨会话对照，完整 ContextCord 将任务通过数从 **33/60 提升至 43/60**：通过率 **55.0% → 71.7%**，提升 **16.7 个百分点 / 相对提升 30.3%**。

| 指标 | 基线 | ContextCord | 变化 |
|---|---:|---:|---:|
| 官方验证器通过任务 | 33/60 (55.0%) | 43/60 (71.7%) | +16.7 pp / +30.3% 相对提升 |
| 通过率的 95% Wilson 区间 | 42.5%–66.9% | 59.2%–81.5% | 各组比例区间 |
| 失败任务 | 27/60 | 17/60 | 减少 10 个 |
| 重复代码探索 | — | −41% | 相对基线 |
| 未缓存输入 Token | — | −29% | 相对基线 |
| 首次正确修改通过验证器的时间中位数 | — | −32% | 相对基线 |
| 类型化决策准确率 | 255/300 (85.0%) | 282/300 (94.0%) | +9.0 pp |
| 决策准确率的 95% Wilson 区间 | 80.5%–88.6% | 90.7%–96.2% | 各组比例区间 |
| 有限对抗集门禁绕过 | — | 0/300 | 95% 精确区间 0–1.22% |

300 个独立标注工程决策中，Jev 类型化判断准确率达到 **94.0%**，较同模型自由文本基线 **85.0%** 提升 **9.0 个百分点**。282 和 255 是由公布的百分比与分母换算的正确决策数。

Adaptive Router 的单独对照结果为：未缓存输入 Token 进一步减少约 **23%**、推理延迟降低约 **18%**，任务成功率的绝对变化控制在 **2 个百分点以内**。

## 协议与任务分母

| 评测 | 统计单位 | 分母 | 对照方式 |
|---|---|---:|---|
| 工程接续 | 真实工程任务 | 每个条件 60 | 同模型、同预算、跨会话，官方验证器判定 |
| Jev 类型化决策 | 独立标注工程决策 | 每个条件 300 | 类型化判断与同模型自由文本判断 |
| 对抗门禁 | 对抗案例 | 300 | 统计观察到的门禁绕过 |
| Adaptive Router | 路由任务 | — | 成功率约束下比较 Token 与推理延迟 |

工程接续以任务为配对单位。会话数量、验证器重试数与工程决策数量分别统计；工程任务失败保留在 60 个任务的分母内。

## 置信区间

通过率与决策准确率采用双侧 **95% Wilson score** 区间，z = 1.959963984540054。门禁绕过采用双侧 **95% Clopper–Pearson** 精确区间：本有限测试集观察到 **0/300**，区间为 **0–1.22%**。

表中区间对应各组比例。配对提升的区间需要逐任务配对或不一致计数，因此汇总 JSON 的配对区间字段使用 null。探索、Token、时间与 Router 指标公开相对变化值。

## 指标定义

- **任务通过率**：通过官方验证器的任务数 / 工程任务分母。
- **绝对提升**：(43/60 − 33/60) × 100 = 16.6667 个百分点。
- **相对提升**：(43/33 − 1) × 100 = 30.3030%。
- **重复探索**：跨会话对相同源码目标重复导航、搜索或读取。
- **未缓存输入 Token**：provider 输入 Token 减去缓存输入 Token。
- **首次正确修改通过验证器时间**：从接续起点，到正确修改首次通过官方验证器的耗时；公开指标为时间中位数的相对变化。
- **类型化决策准确率**：正确的独立标注决策数 / 全部标注决策数。
- **门禁绕过率**：观察到越过既定门禁的未授权行为数 / 对抗案例数。
- **推理延迟**：路由对照中模型推理阶段的耗时。

降幅统一按 100 × (1 − 实验条件 / 基线条件) 计算。
