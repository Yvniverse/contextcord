# Code of Conduct

ContextCord adopts the **Contributor Covenant, version 2.1** as the baseline for community participation. The canonical text and enforcement guidelines are maintained at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Project expectations

ContextCord is a technical community. Disagreement about APIs, evidence, benchmarks, architecture or product direction is welcome when it stays respectful and specific. Critique ideas and artifacts, not people. Do not harass, threaten, discriminate against, impersonate, or publish private information about another person.

Contributors using coding agents or other generative tools remain responsible for what they submit: review generated material, verify technical claims, and communicate honestly about evidence that affects a technical decision.

## Scope

This Code of Conduct applies to repository issues, pull requests, reviews, discussions, commit messages, official project channels, and situations where someone is representing ContextCord publicly.

## Reporting

Report conduct concerns privately to the project maintainer through a private contact method published by the `Yvniverse` GitHub account. Do not place sensitive conduct reports in a public issue. If the project later publishes a dedicated conduct contact, this section should be updated to that single canonical address.

Security vulnerabilities follow the separate process in [SECURITY.md](SECURITY.md).

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards and will use the Contributor Covenant 2.1 enforcement guidelines as the baseline for proportionate action. Maintainers may edit or remove content, reject contributions, restrict participation, or take other reasonable action when project spaces are used in ways that violate these standards.
